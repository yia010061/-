Q ◦ A ≈ I

輸入模糊矩陣 A（元素介於 0 與 1），求逆關係矩陣 Q，並檢視重建結果及距離分析。

Hamming 距離：目標函數、解析算法與結果解讀
1. Max-Min 輸出與 Hamming 成本
b′ⱼ = maxᵢ min(xᵢ, aᵢⱼ),　j=1,…,n
已知 A∈[0,1]ᵐˣⁿ，未知列向量 x∈[0,1]ᵐ。先用 max-min 合成得到預測輸出 b′=x◦A，再把每個分量與指定目標 b 比較。
D(x◦A,b) = Σⱼ₌₁ⁿ |bⱼ − b′ⱼ|
這個未正規化的絕對誤差總和就是 Cost Function／Goodness Measure：成本越低，近似解越好；D=0 表示每個分量都完全符合目標。單列距離範圍是 [0,n]。
2. 逆關係的整體最佳化
Dₖ* = minₓ∈[0,1]ᵐ D(x◦A,eₖ),　k=1,…,n
D(Q◦A,I) = Σₖ₌₁ⁿ Dₖ*,　0 ≤ D(Q◦A,I) ≤ n²
每一列 q⁽ᵏ⁾ 分別對應單位向量 eₖ；總距離是 n 個目標列成本的總和，因此比較不同欄數的矩陣時，須留意總距離也會隨目標列數增加。除以 n² 可作 0 到 1 的尺度參考，但此工具顯示的最佳化成本仍是原始總和。
精確解判準
A 的每個單位向量列 e₁,…,eₙ 都出現時，精確逆關係存在；此時 Q◦A=I 且總距離為 0。否則顯示最佳近似解。
3. 解析算法為何只檢查折點
針對每個目標 eₖ，先把 A 的第 k 欄換到第一欄。固定一個 A 的列 i，令該解只有第 i 個分量為 t，其餘分量為 0，則該候選解的距離為：
Eᵢ,ₖ(t) = 1 − min(t,aᵢₖ) + Σⱼ≠ₖ min(t,aᵢⱼ),　0≤t≤1
min(t,a) 只會在 t=a 改變斜率，因此 Eᵢ,ₖ(t) 是分段線性函數。每一段的最小值必在端點，故只需比較 t=0、t=1 與該列 A 元素形成的折點。論文的下界結果指出，任意向量解的成本不會低於某個單列候選 Eᵢ,ₖ(t)；而把 x 設成只有第 i 項為 t，就能實際達到該候選成本。因此比較所有 i 與折點 t，所得最低值就是全域最小成本。若有並列最佳值，結果表顯示其中一組。
4. 範例：逐項計算近似成本
A = [[0.3,0.5],[0.7,0.8],[0.8,0.9]]
對 e₂=[0,1]，一組最佳解取第 1 列、t=0.5，即 x=[0.5,0,0]。Max-Min 輸出為 b′=[min(0.5,0.3),min(0.5,0.5)]=[0.3,0.5]；逐項誤差為 [|0−0.3|,|1−0.5|]=[0.3,0.5]，故 D₂=0.8。對 e₁ 的最佳距離為 1，所以總距離 1+0.8=1.8。載入「範例 2：近似解」可查看完整矩陣、誤差表和長條圖。
